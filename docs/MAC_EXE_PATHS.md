# Mac app：其他几部游戏对照原版 EXE

静态阅读各游戏的 EXE 得出，原版没有运行过。地址只对手上的版本有效。
开关都是 `PcHost.followsExe`，只在 Mac app 打开，其他平台和 `--audit` 不变。
`PcHost.exe()`、`DesktopLegacy.followsExe()` 含 DC2PC 和 Vista，`followsPc2Exe()` 只含 DC2PC，`followsDm()` 只含 DM。
D.C.III 的判断在 `Dc3Host` 和 `DesktopDd`：`followsPp()` 是 P.P.，`ui.keepsPanels` 是 D.D. 和 W.Y.。

## D.C.P.C. Vista（`dcpc-2063`，脚本标记 `0x3D63`）

和 DC2PC 同一代架构，以下相反或不同：

| 项目 | Vista |
|---|---|
| 音效 | 单声道（`41CB40`） |
| 音量 | 1 dB 一档（`41C510`） |
| 音乐解锁 | 没有 bank 95，曲名在脚本图里 |
| 默认设置 | `42D078`，r9=30、r11=4、r12=1 |
| 随机数结果 | 写 r2（`415085`） |
| 人名 | 28 px（`417F20`） |
| 文字阴影 | 恒为调色板 0（`4175AA`） |
| 悬停图层 | state 3、4 也画（`40A221`） |
| 滚轮下 | 不推进（`419A08`） |
| Skip 按钮 | r251 为 0 时不显示不命中（`41302E`） |
| 脚本调用 | `0x26` 加 `0x46` 记录（`415247`） |
| 效果 14 | 主要是 `[14,9]`（`410E1C`），约 1880 ms |
| 存档行 | 标题是脚本日历，如 `２月２３日（日）`（`4049D0`） |

**没做：** `pc.sound8 [255,1]` 的 300 ms 淡出。**没查清：** r21、r3、r22 的 wmv 选择。

## D.C.II Dearest Marriage（`dc2dm-9d72`）

版面常量在 `PcText.DM`：22 px，全角 21，半角 10，假名 12，含注音的行下移。

- **等待和淡变：** `[n,f]` 首拍立即（`42D019`）。淡变 127 级 34 ms，默认 272 ms（`4313EF`）。
- **输入：** 第一个命中优先，点击不打断无 bit0 的等待。定时等待右键走动作槽 3，左键走 2（`4333B0`）。
- **AUTO：** `((20-r29)*5+1)*30` ms，r13 开关（`42CFA2`、`434440`）。
- **声音：** 两声道，曲线 `(min(2*lv,60)-60)*83`（`4350F0`），停止放过 223（`436120`）。
- **Music：** 滚轮 10 行，滚动条可拖，顶部条 `@s%03d : %s`（`414907`）。
- **Quick：** 写槽 1 并复制到槽 3，`[9,7]` 时禁用（`43416A`）。

**没做：** Quick 的确认框，AUTO 面板的绘制（按钮已接），SE 的 `[-1,1]` 淡出，`@o`、`@x` 标签。
**没查清：** 粒子转场 16、17、20、21 的时长，存档行字段，LOG 布局，回看上限。

## D.C.III D.D. 和 W.Y.

两部几乎同一份代码，每帧全量重绘。版面常量在 `PcText.DC3`。

- **正文：** 22 px，假名 14 px 在等宽格内居中（`43CC50`）。行距 34，只按换行分行。
- **打字机：** 按行像素擦除，每帧 `2*r26+8` 像素（`43F3E0`）。帧按 60 帧/秒换算，这是推断。
- **工具条：** `:n` 翻转 r227 切模板 9、10（`429059`），`:ds`、`:dl` 进存读档（`428C15`）。
- **面板：** 点击后保留到 `ui.panel[0]` 或转场 2、16、17、20、21（`4339D5`、`4203A0`）。
- **动作槽：** 任何等待都响应动作 2、3（`433F8C`）。
- **淡变：** `(5a+5)*4` 帧再按 r12 缩放（`42CA88`、`40EAB0`），右键可打断。
- **音量：** -50 到 0 dB 线性（`43B5D0`），BGM ducking（`432EAA`）。
- **存档槽：** Quick 写槽 2，自动写槽 0（`428C79`、`42DE0D`）。
- **W.Y. 专属：** `[206,0]`、`[207,0]`、`[205,0]`（`4096BF`、`409759`）。

**有意和原版不同：** F9 在原版开设置，这里仍是快速读取，和 app 菜单一致。

- **W.Y. 音乐页：** 曲目表是它自己的 74 首，不是 D.D. 的 88 首。

**没做：** Quick 的确认框，换曲 60 帧淡出，已读 Skip（`423CC0`），小说模式模板 5、6，鼠标手势，W.Y. 的效果 `[2,n]`。
`system.persist [22..25]` 是存档导出和导入，推断要走文件对话框，这里一律按取消处理。

碎片转场 16 在这三部里都还是交叉淡化，没有碎片动画。

## D.C.III P.P.

DirectDraw 和 DC2PC 同代，不是 D.D. 的架构。版面用 `PcText.DM`。

- **BGM：** `0x05` 是音乐命令（`42C089`）。原来绑错，整部没有音乐。
- **Music 页：** `[11,*]`、`[12,*]`、`[212,*]`（`412D5C`、`412DD5`、`4132FE`）。
- **等待：** `429052` 的位标志。`[n,8]` 按立绘动画结束处理是推断。
- **淡变：** 同 DM（`42D1E0`）。默认表 `478110`。
- **音量：** 同 DC2PC（`430DA0`），两声道。推进无条件停语音（`428172`）。
- **输入：** 按下补全、松开不推进（`42DCE1`），第一个命中优先（`41C260`），菜单保留到下次绘制。
- **其他：** `[206,0]` 取最高好感（`4131B7`），`:option` 进 OPTION。

**没做：** 日历动画 `[207,0]`（`4126C0`），`[210,0]`、`[211,0]` 的原生动画，这三处脚本会直接跳过。
也没做自动模式顶部条的绘制（`:a` 系按钮已接），`0x3F`、`0x40` 按钮语音，人名居中。
**没查清：** OPTION 滑杆换算（`41B940`），`403B80` 的对象。

## 所有游戏

安装里缺的声音文件按静音处理，不再停游戏。
