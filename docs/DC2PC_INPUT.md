# D.C.II P.C.：对照原版 EXE

静态阅读 ARCHIVES 版 `DC2PC.exe`（脚本标记 `0x9969`）得出，原版没有运行过。
地址只对这个版本有效，`VM_SPECIFICATION.md` 记的是另一个版本的地址。
只有 Mac app 走这条路径（`PcHost.followsExe`），其他平台和审计不变。

| 地址 | 原版行为 | 引擎原来的问题 |
|---|---|---|
| `41D530` | 只有菜单等待和文字等待跟踪鼠标，定时等待不跟踪 | 任何时候都跟踪 |
| `411B90` | 跳过不可用和条件隐藏的按钮，第一个命中优先，切到别的按钮才响 | 不过滤，最后一个命中优先 |
| `412B60` | 网格行变化时响悬停音效，寄存器 253 就是悬停行 | 网格没有悬停音效 |
| `411ED0` | 点击也用同样的命中规则 | 不过滤，最后一个命中优先 |
| `4248F8` | 按钮语音（`0x3D`）把点击音效设为 `0xFF`，有语音就不响音效 | 两个都放 |
| `4281D0` | 音效有两个声道，新音效只打断两个里较旧的 | 一个声道，每次都打断 |
| `422922` | 菜单等待时音乐没在播，就跳到 `ui.music_end_action` | 一致，见下 |

**Music Mode：** `music.mes` 的 `all_play_chk` 会回到 `menu` 重新绑定回调，所以没有音乐时菜单每帧重建，原版也是如此。
原版松开鼠标时直接对当前界面做命中测试。引擎的 `pointerUp` 还要求按下后 `ticket` 没变，这是触屏逻辑，于是点击全被取消。
现在同一个控件还在鼠标下时，重建不再取消点击。

**有意和原版不同的一处：** `0x17`（`4245BE`）重建菜单时会清掉悬停状态，所以原版在每帧重建期间，鼠标每动一下都可能再响一次。
这里记住鼠标下的按钮，同一个按钮不重复响。

## 画面和时序

原版屏幕是持久的 surface。点击和定时等待都不重绘，构建中的按钮不上屏。

| 地址 | 原版行为 | 现在的做法 |
|---|---|---|
| `424523` | 定时等待只有脚本画过东西才重绘（`0x0D [10]`、`0x21 [0]`、`0x30`、`0x53`） | 菜单画面冻结到下一次发布，淡变从这张画面开始 |
| `4252BA` | `0x0D [10]` 把 quad 烘焙进背景，不显示，0 毫秒 | quad 存进 `quadTemplates[0]`，同时记下当时的图片名 |
| `42448F`、`422548` | `pc.wait [n,0]` 是 `(n-1)×200` 毫秒；bit 0 可点击结束，bit 1 改 100 毫秒，bit 2 按绝对时钟，bit 3 改 10 毫秒 | 一致。bit 2 的锚点处理是推断 |
| `423470`、`41D672` | 淡变 16 级，每级 40 毫秒，步进由 `619CE8`（寄存器 12）决定，共 640、320、160、80 毫秒 | 一致 |
| `4252BA`、`425389`、`4251AD` | `[5,0]`、`[12,0]` 直接切 | 一致 |
| `424DC2` | `dm.ui.commit` 画到离屏 | 不发布 |
| `421C40` | 立绘移动按距离滑动，每 tick 10 毫秒 | 时长一致，**画面是交叉淡化，不是滑动** |
| `4720C8` | 默认设置 7、8、9、11、12、16、20 为 25、25、29、8、1、8、1 | 一致，旧 `progress.dat` 里未改过的旧默认值会迁移 |

## 正文

| 地址 | 原版行为 |
|---|---|
| `41C970`、`41C230` | 注音写作全角 `｛かな／漢字｝`。基字 28px 等宽，只在换行符处换行，没有自动折行和禁则 |
| `41CA2F`–`41CBED` | 假名 12px，高出 11px，按基字宽度分散；放不下时向两侧溢出，不推挤邻字 |
| `41C8A6` | 假名是 `・` 时，用 28px 画在 `(X-8, Y-5)` |
| `421F90` | 打字机每 tick 走一格，`｛…／`、`｝`、换行各占一格，假名不占格 |
| `41F7D0` | 人名 24px，以名牌为中心 |
| `40BAD4` | 字体是 ＭＳ ゴシック。Mac 没有这个字体，这里用 Hiragino Sans，字形必然和原版不同 |

## 声音和输入

| 地址 | 原版行为 |
|---|---|
| `420360` | 点击推进时停语音 |
| `40AF6F`、`4232BD` | 打字中按下补全全文，这次松开不再推进 |
| `40AF0A`、`422BBF` | 淡变中不收输入，定时等待只有 bit 0 才可点击 |
| `4281D0`、`42430A` | 循环音效独占声道，一次性音效不打断它，停止指令全部停 |
| `4273A0` | 音量是对数曲线，BGM 再减 3 dB |
| `429099` | 换曲时旧曲快速淡出 |
| `4203B0` | 读档不恢复语音和一次性音效 |
| `40B39A`、`41D310` | 滚轮翻页和翻回看，回看里点正文重播语音 |
| `40AD71` | 空格隐藏文字窗 |

## 还没做

- 选择支期间的工具条、右键菜单和滚轮（`424D22`、`4232D6`）。
- Skip 的细节：`:rapid` 和 Ctrl 分开、右键清除、寄存器 242。
- 回看上限 999 条（现在 200）。
- 存档行的标题表和日期格式（`4078E0`），确认框时背后的存档行（`425261`）。
- 快速存档的闪白（`41D980`）和键盘方向键导航（`413E40`）。
- `0x0D` 的 13、14、51、52 和粒子转场 `419310` 的准确时长。
- 雪和花瓣在定时等待中是否继续动：现在冻结画面时它们会停 200–800 毫秒。
